# NovaCart - Digital Store

## Project Overview

NovaCart is a demonstration e-commerce storefront developed to simulate
digital retail operations without using Shopify or other CMS platforms.

The project demonstrates product catalog management, structured SKUs,
inventory tracking, category organization, shopping cart functionality,
and a basic customer checkout workflow.

## Objective

To build and configure a functional e-commerce storefront that simulates
real-world retail catalog and inventory operations using HTML, CSS and
JavaScript.

## Key Features

- Responsive e-commerce storefront
- Product catalog with 15 products
- Product categories
- Structured SKU management
- Product descriptions optimized for search visibility
- Product pricing
- Inventory tracking
- Low-stock and out-of-stock indicators
- Add-to-cart functionality
- Shopping cart management
- LocalStorage-based cart persistence
- Category-based product organization
- Responsive design for desktop and mobile screens

## Product Catalog

The catalog contains structured product information including:

- Product ID
- Product Name
- SKU
- Category
- Price
- Inventory Quantity
- Product Description

## Inventory Management

Products are assigned inventory quantities and automatically display
different stock statuses:

- In Stock
- Low Stock
- Out of Stock

## Shopping Cart

Customers can add available products to the shopping cart.

Cart information is stored using browser LocalStorage, allowing cart
data to remain available during the browsing session.
